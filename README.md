
# Aplicação de Tarefas

Aplicação web de gerenciamento de tarefas desenvolvida com React, implementando rotas, estado, efeitos e contexto.

## 📋 Descrição

Projeto desenvolvido com a finalidade de avaliação do **Desafio 2 - Aplicação de Tarefas com Rotas, Estado, Efeito e Contexto** do curso DevStart SENAI, focando em práticas essenciais de React como:
- Roteamento com React Router
- Gerenciamento de estado global com Context API
- Efeitos colaterais com Hooks

## ✨ Funcionalidades

- ✅ Listagem de tarefas
- ✅ Adicionar nova tarefa
- ✅ Editar tarefa existente
- ✅ Excluir tarefa existente
- ✅ Alterar status da tarefa com toggle
- ✅ Navegação entre páginas

## 🛠️ Tecnologias

- React
- React Router DOM
- Context API
- CSS

## 🚀 Como usar

1. Clone o repositório do Git: 
```bash 
git clone https://github.com/calvarengapb/aplicacao-de-tarefas.git
```
2. Instale as dependências:
```bash 
cd aplicacao-de-tarefas
```
2. Instale as dependências:
```bash 
npm install
```
2. Inicie a aplicação: 
```bash
npm start
```
3. Acesse em `http://localhost:3000`
